\hypertarget{md__r_e_a_d_m_e_autotoc_md4}{}\doxysubsection{\texorpdfstring{What is the turing test?}{What is the turing test?}}\label{md__r_e_a_d_m_e_autotoc_md4}
\href{https://plato.stanford.edu/entries/turing-test/}{\texttt{The turing test}} is a test purposed by Allen Turing in 1949. It is a test of computers against the intellect of humans. It is performed with two humans, the {\itshape human} and the {\itshape interrogator}, and one computer whose goal is to impersonate a human. The interrogator will ask questions to the human and computer for 5 minutes. Turing thought that digital computers would, with enough computational power, be able to fool the interrogator 70\% of the time. This happens to be a very difficult task something that LLM have only recently been able to accomplish well.

In the context of this project we will wrestle with this test and I think if we succeed in making bots able to fool a human player into thinking they are a human we’ll be successful. In making the game bigger however and making the game more centered around questioning I think it may make it simpler for computers to imitate humans. Every person is both and interrogator and a player so it will be difficult for one to make obscure questioning line with out skepticism. I hypothesize this will make the corpus of language used inside of the game much smaller and therefore easier to duplicate. I think the most difficult thing to replicate is mistakes that human players will make. It will be interesting to see if we can successfully create a text corpus to duplicate mistakes well and be able to confuse a variety of people from different ages and backgrounds. Further research in its ability to play the game in other languages could also be interesting.\hypertarget{md__r_e_a_d_m_e_autotoc_md5}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{md__r_e_a_d_m_e_autotoc_md5}

Ultimately the end product should be an engaging game that demonstrates the current state of the turing test with the aid of LLMs. The sign we have reached our goal is the capability of our model(s) to fool a human player into thinking the model is also human. Furthermore, if the bots themselves struggle to distinguish humans from the bots we have accomplished our goal.\hypertarget{md__r_e_a_d_m_e_autotoc_md7}{}\doxysection{\texorpdfstring{MVP}{MVP}}\label{md__r_e_a_d_m_e_autotoc_md7}
With the AI model being the most unknown and potentially time consuming part of this project I think it is important we build out a low fidelity interface for the AI bots. The easier it is to interface the bots with the application the better and faster we can work to create the best bots. Also, the application should hopefully be designed with plenty of responsiveness with timing and latency being a factor in the game. I propose we design and build out a proper backend and web API. Then we can build out a front end to update a use r on the state of the game and use those same API calls to communicate with the bots what the state of the game is. For its current purposes the bots can respond the same way each time or answer basic questions based off pre generated lists.

Use the helper script to launch the stack whether you are on mac\+OS or Windows\+:


\begin{DoxyEnumerate}
\item Install \href{https://www.docker.com/products/docker-desktop/}{\texttt{Docker Desktop}} and make sure it is running.
\item Open a terminal (mac\+OS) or Power\+Shell (Windows) at the repo root and run\+:
\begin{DoxyItemize}
\item mac\+OS/\+Linux\+: {\ttfamily ./scripts/dev.sh up}
\item Windows Power\+Shell\+: {\ttfamily bash scripts/dev.\+sh up} (requires Git Bash or WSL) or run the commands inside WSL.
\end{DoxyItemize}
\item The script will\+:
\begin{DoxyItemize}
\item Generate {\ttfamily .env} with a random {\ttfamily SECRET\+\_\+\+KEY} if it does not exist.
\item Build the Flask image.
\item Launch the stack defined in {\ttfamily docker-\/compose.\+yml} (Flask at {\ttfamily \href{http://localhost:5000}{\texttt{http\+://localhost\+:5000}}} by default).
\end{DoxyItemize}
\item When you are finished, run {\ttfamily ./scripts/dev.sh down} (or {\ttfamily bash scripts/dev.\+sh down} on Windows) to stop everything. Add {\ttfamily -\/d} to run detached ({\ttfamily ./scripts/dev.sh up -\/d}) and use {\ttfamily ./scripts/dev.sh logs flask-\/app} to follow logs.
\item If Windows reports permissions errors running the script, execute the commands inside WSL ({\ttfamily wsl} → {\ttfamily cd /mnt/c/\+Users/.../capstone\+Project} → {\ttfamily ./scripts/dev.sh up}).
\end{DoxyEnumerate}

{\bfseries{Enabling the Open\+AI cloud bots\+:}} add both {\ttfamily OPENAI\+\_\+\+API\+\_\+\+KEY=...} and {\ttfamily CAPSTONE\+\_\+\+ENABLE\+\_\+\+CLOUD\+\_\+\+BOTS=1} to {\ttfamily .env} before running {\ttfamily ./scripts/dev.sh up}. Those settings start the {\ttfamily bot1}/{\ttfamily bot2} containers (disabled by default so the stack still works without API access).

{\bfseries{Custom host port\+:}} mac\+OS Control Center already listens on port 5000. If you hit the “address already in use” error, set {\ttfamily CAPSTONE\+\_\+\+HOST\+\_\+\+PORT=5050} (or any free port) in {\ttfamily .env} and rerun {\ttfamily ./scripts/dev.sh up}. Docker will map that host port to the container’s 5000.

{\bfseries{Using local AI bots with Docker (mac\+OS/\+Windows)\+:}}


\begin{DoxyEnumerate}
\item On the host OS (not in Docker) run {\ttfamily python \doxylink{setup__local__agents_8py}{scripts/setup\+\_\+local\+\_\+agents.\+py}}. On Windows, run this in Power\+Shell or WSL using the Python that has network access.
\item Ensure Ollama is running on the host ({\ttfamily ollama serve}). Keep {\ttfamily OLLAMA\+\_\+\+URL=\href{http://host.docker.internal:11434}{\texttt{http\+://host.\+docker.\+internal\+:11434}}} in {\ttfamily .env} so the containerized Flask app can reach the host’s Ollama endpoint.
\item Start the stack with {\ttfamily ./scripts/dev.sh up} (or {\ttfamily bash scripts/dev.\+sh up} on Windows) and open the UI in a browser.
\item In the lobby, switch to {\bfseries{Local AI agents}}. The Flask container will spawn {\ttfamily \doxylink{local__agent_8py}{Bot/local\+\_\+agent.\+py}} processes that talk to the host’s Ollama server via {\ttfamily host.\+docker.\+internal}.
\end{DoxyEnumerate}
